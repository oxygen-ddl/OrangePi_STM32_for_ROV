# 水下机器人 PWM 推进器控制系统

## 🎯 项目概述
基于**香橙派+STM32双机架构**的水下机器人推进器控制系统，实现8通道PWM的可靠驱动与多重安全保护，为ROV（遥控水下机器人）提供硬件级安全保证。

## 🏗️ 系统架构

### 三层设计
```
操作层 (pwm_teleop) → 控制层 (pwm_control) → 通信层 (libpwm_host) → STM32执行层
```

### 硬件组成
- **上位机**：香橙派（OrangePi）运行控制程序
- **下位机**：STM32F407/F446处理PWM输出
- **通信**：UDP over Ethernet + 自定义协议

## ⚡ 核心特性

### 1. 多重安全保护机制
- **限斜率保护**：单步最大0.2%变化，防止电流冲击
- **A/B分组输出**：CH1-4与CH5-8交替更新，降低瞬时负载
- **反向保护**：禁止直接跨越中位反转
- **心跳监控**：500ms超时自动回中位保护
- **平滑急停**：可配置时间平滑归中

### 2. 可靠通信协议（Protocol V1）
- **帧结构**：SOF(2B)+VER(1B)+MSG_ID(1B)+SEQ(2B)+TICKS(4B)+LEN(2B)+PAYLOAD(N)+CRC16(2B)
- **消息类型**：PWM控制(0x01)、心跳(0x10)、心跳应答(0x11)、紧急停止(0x20)
- **CRC16校验**：确保数据完整性

### 3. 操作控制
**键盘映射**：
- 数字键1-8：单通道阻塞测试
- WASD：水平运动控制
- QE：航向控制
- GH：垂直运动
- RT：横滚运动
- FV：翻转运动
- M：全通道回中位

### 核心测试流程
1. **心跳验证**：RTT < 10ms，断线保护生效
2. **PWM输出验证**：8通道独立，周期20ms
3. **安全机制验证**：限斜率、分组输出、急停功能
4. **异常恢复测试**：通信中断、CRC错误处理

## 📊 工程价值

### 安全性设计
> 核心理念：不论上层控制算法是否成熟，本系统都能确保推进器硬件安全

### 可靠性保证
- 模块化架构，各层完全解耦
- 完整的错误处理和容错机制
- 支持从手动遥控到MPC自动控制的平滑升级

### 适用场景
- 水下机器人推进器控制
- 多电机协同驱动系统
- 需要高可靠性PWM控制的机器人平台
