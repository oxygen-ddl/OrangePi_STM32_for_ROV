## 更新文档草案 (PWM 模块相较于原版的改动与使用说明)

### 1. 变更摘要

* 新增**统一时间基模块** (timebase) 用于控制循环与传感器系统的时间同步。
* 主循环过程中**实时记录 PWM 下发指令日志**，文件保存为 `logs/pwm_teleop_<时间>.csv`。
* 键盘 teleop 逻辑支持**多自由度叠加控制** (overlay)，实现类似手柄操作的控制体验。
* 大动作键**保持独占触发**，不可与其他按键叠加，作为工程安全保护。
* 控制频率配置由估算周期改为**主循环驱动**，确保 AB 交替模式下总调度频率可稳定达到 100Hz。

---

### 2. 具体改动项

#### 2.1 统一时间基 (Timebase)

* 位置：`external/timebase/timebase.cpp` 与 `external/timebase/timebase.h`
* 负责：

  * 获取系统**system_clock + steady_clock 双时间**
  * 提供 `timebase_now()`、`timebase_steady()`、`timebase_sync()` 等接口
  * 用于主循环时间戳与后续传感器模块对齐 (IMU 100Hz / DVL 10Hz)

#### 2.2 PWM 日志记录

* 位置：主程序 `main.cpp` (teleop 主循环内部)
* 记录内容：

  | 字段                 | 说明               |
  | ------------------ | ---------------- |
  | `t_s`              | 自循环开始的秒级时间偏移     |
  | `ch1_pct..ch8_pct` | 已下发的 8 路 PWM 占空比 |
* 触发方式：

  * 程序启动后自动创建 logs 目录并生成日志文件
  * 主循环每次执行 `pwm_ctrl_step()` 后写入一行新记录
  * 程序退出时自动 `flush` 并 `close`

#### 2.3 键盘控制逻辑重构 (overlay)

* 位置：`pwm_teleop_keys.cpp`
* 支持：

  * **非冲突按键叠加**：

    * `W`/`S`/`A`/`D`/`Q`/`E`/`G`/`H` 之间可组合，例如：

      * `W + A + E → 前进 + 右移 + 右转`
      * `S + H → 后退 + 上浮`
  * **大动作键独占保护** (不可叠加)：

    * `ROLL_LEFT` / `PITCH_FLIP` （你可自定义具体键位，如 `R` / `T`）
    * 这些键会直接覆盖 motor 输出模式，并在触发期间屏蔽 overlay

#### 2.4 控制频率设置收敛为主循环驱动

* `s_cfg.ctrl_hz` 作为**参考频率**用于估算 max_step_pct (限斜率)
* 实际 step 由主循环定时驱动，而 not 依赖内部 sleep 估算周期

### 3. 使用说明

#### 3.1 编译与运行

```bash
# 在项目根目录执行
mkdir -p build && cd build
cmake ..
make -j4
./pwm_teleop 192.168.2.16 8000 100 2
```

* 参数说明：

  * `192.168.2.16` → STM32 设备 IP (默认亦可)
  * `8000` → 设备端口
  * `100` → **控制总频率 100Hz**
  * `2` → 心跳频率 2Hz (可选参考)

#### 3.2 日志文件位置与命名规则

```
pwm_control_program/logs/
  ├─ pwm_teleop_2025-11-26_18-15-20.csv
```

* 该文件会在程序**运行开始时自动创建**
* 不同实验日志不会覆盖，以时间戳区分

#### 3.3 键位控制逻辑

| 键位          | 类型     | 行为                                  |
| ----------- | ------ | ----------------------------------- |
| `1..8`      | 单电机测试  | 7.5%→9% 保持3秒→平滑回7.5%（阻塞）            |
| `W`/`S`     | 水平控制   | 前进/后退 (m=mid + delta / mid - delta) |
| `A`/`D`     | 横向控制   | 左移/右移                               |
| `E`/`Q`     | Yaw 控制 | 右转/左转                               |
| `G`/`H`     | 垂向控制   | 下潜/上浮                               |
| `R`/`T`（示例） | 大动作    | Roll/Pitch 翻转 **独占触发，不可与其他键叠加**     |
| `M`         | 归中     | 所有通道回7.5%                           |
| `ESC`       | 退出     | 平滑拉中 + 关闭日志并退出                      |

* overlay 组合控制示例：

  * `W` + `D` + `E` → 机器人**前进 + 左移 + 右转**
  * `S` + `G` → 机器人**后退 + 下潜**
  * `H` + `E` → 机器人**上浮 + 右转**
* 注意：

  * 大动作按键 (ROLL / PITCH) 触发期间**不参与叠加**
  * 其他键叠加期间均受 `max_step_pct` **限斜率保护**平滑逼近目标

---

### 4. 工程注意事项

* 带电初测建议**空载断桨运行**
* 总控制频率 AB alternate 模式下建议**=100Hz**
* 日志以本地控制 loop 执行 step 的瞬间为时间戳，不涉及网络发送延迟
* 心跳与 ACK 仅用于 RTT 诊断，不参与 PWM 日志节拍
* 后续传感器对齐依赖 timebase steady 时间
