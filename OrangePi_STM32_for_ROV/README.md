# 香橙派（上位机）与 STM32（下位机）之间的通信与电机驱动控制

## 项目概述

本项目实现了 **香橙派（上位机）与 STM32（下位机）之间的通信与电机驱动控制**，核心功能包括：

* 香橙派通过 UDP 协议周期性发送 8 路 PWM 控制指令及心跳包；
* STM32 通过 UART5 接收数据帧，解析协议、校验 CRC；
* STM32 根据指令驱动 8 路 PWM 输出；
* 若通信超时（心跳丢失），自动进入失联保护模式，将 PWM 置中位。

## 系统架构

### 硬件组成
- **上位机**：香橙派（OrangePi）运行控制程序
- **下位机**：STM32F407 处理 PWM 输出
- **通信**：UDP over Ethernet（模拟串口协议）

### 软件架构
```
Teleop/MPC控制层 → PWM控制层（安全保护） → 通信层 → STM32执行层
```

## 核心特性

### 安全保护机制
- **限斜率保护**：单周期最大变化 0.2%，防止电流冲击
- **A/B分组输出**：CH1-4 与 CH5-8 交替更新，降低瞬时负载
- **反向保护**：禁止直接跨越中位反转
- **心跳监控**：500ms 超时自动回中位
- **平滑急停**：可配置时间的平滑归中

### 通信协议（Protocol V1）
- **帧结构**：SOF(2B) + VER(1B) + MSG_ID(1B) + SEQ(2B) + TICKS(4B) + LEN(2B) + PAYLOAD(N) + CRC16(2B)
- **消息类型**：PWM控制(0x01)、心跳(0x10)、心跳应答(0x11)、紧急停止(0x20)
- **校验**：CRC16-CCITT-FALSE 确保数据完整性

## 快速开始

### 环境准备
**STM32端**：
- Keil uVision5 + STM32 HAL库
- 配置 UART5 DMA 接收，TIM1/TIM4 PWM 输出

**香橙派端**：
```bash
cd orangepi_send
mkdir build && cd build
cmake .. && make -j4
```

### 运行程序
```bash
./orangepi_send 192.168.2.16 8000 51 1
# 参数：目标IP、端口、控制频率(51Hz)、心跳频率(1Hz)
```

## 测试验证

### 基本测试流程
1. **心跳验证**：检查 RTT < 10ms，断线保护生效
2. **PWM输出验证**：确认 8 通道独立输出，周期 20ms
3. **安全机制验证**：限斜率、分组输出、急停功能
4. **异常测试**：CRC错误、通信中断、重启恢复

### 关键验收标准
- ✅ 心跳稳定，断线 500ms 内回中位
- ✅ 8通道 PWM 输出正确，无毛刺
- ✅ 安全保护机制全部生效
- ✅ 系统复位后可正常恢复

## 工程价值

- **安全性**：多层保护防止硬件损坏和系统失控
- **可靠性**：心跳监控 + CRC 校验确保通信质量
- **可扩展性**：模块化设计支持 MPC、ROS、自动控制等扩展
- **可维护性**：清晰的三层架构，便于调试和升级
