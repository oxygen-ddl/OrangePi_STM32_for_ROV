# 《PWM Teleop 操作说明文档》

**版本：v1.2**
**适用组件：libpwm_host / pwm_control / pwm_teleop_keys**
**适用硬件：Orange Pi + STM32 PWM 驱动板（8 通道）**
**文档目录：`pwm_control_program/docs/pwm_teleop_user_manual.md`**

---

## 1. 系统结构概述

本 PWM 控制程序采用 *三层结构* 设计，确保安全、稳定、可扩展：

```
+-----------------------------------------------------+
|                     Teleop 层                       |
|         (键盘遥控 / 单电机测试 / 任务逻辑)         |
|             pwm_teleop_keys.h / cpp                 |
+-----------------------------------------------------+
|                    Control 层                        |
|    (平滑、电流限制、分组调度、限斜率、逻辑驱动)     |
|                      pwm_control.c                  |
+-----------------------------------------------------+
|                    Host 网络层                       |
|    (UDP 打包、序列号、心跳、ACK、CRC、重传统计)     |
|                      libpwm_host.c                  |
+-----------------------------------------------------+
|                    STM32 PWM 输出                    |
|                  (8 通道脉冲 1000–2000us)           |
+-----------------------------------------------------+
```

特点：

* **安全限斜率**：禁止 PWM 突跳、防止电流冲击
* **分组更新**：默认 CH1–4 与 CH5–8 分两组交替调度 → 降低供电瞬时负载
* **阻塞/非阻塞能力**：工程测试与实时 teleop 均可使用
* **可靠通信**：心跳（1 Hz）、ACK、RTT 测量

## 2. 键盘 Teleop 功能说明（操作手册）

程序启动：

```bash
./pwm_control_program 192.168.2.16 8000 50 1
# 或简写
./pwm_control_program
```

进入 RAW 模式后，使用键盘直接控制 8 个电机输出。

### 2.1 数字键 — 单电机阻塞式测试（示波器测试）

用途：验证电机/PWM/供电模块是否稳定，不涉及机器人运动。

| 按键      | 功能          | 说明                          |
| ------- | ----------- | --------------------------- |
| **1–8** | 测试对应通道单电机输出 | 7.5% → 9% 平滑过渡 → 保持 → 平滑回中位 |

流程：

1. 所有通道归中 7.5%
2. 指定通道输出 9%（平滑渐变）
3. 持续 **3 秒**
4. 平滑归中位

**此操作为阻塞式**（主循环暂停按键读取）。
适用于：示波器测量、单通道校准、电机/驱动安全检查。

---

### 2.2 水平平面运动（Surge / Sway）

| 按键    | 行为 | 推进器模式        |
| ----- | -- | ------------ |
| **W** | 前进 | CH3 + CH4 正转 |
| **S** | 后退 | CH1 + CH2 正转 |
| **A** | 右移 | CH1 + CH3 正转 |
| **D** | 左移 | CH2 + CH4 正转 |

---

### 2.3 航向角控制（Yaw）

| 按键    | 行为 | 推进器模式        |
| ----- | -- | ------------ |
| **Q** | 左转 | CH1 + CH4 正转 |
| **E** | 右转 | CH2 + CH3 正转 |

方向含义需与实际推进器布局核对。

---

### 2.4 垂向运动（Heave：上升/下降）

| 按键    | 行为 | 推进器模式                 |
| ----- | -- | --------------------- |
| **G** | 下潜 | CH5、CH8 正转；CH6、CH7 反转 |
| **H** | 上浮 | CH6、CH7 正转；CH5、CH8 反转 |

这些模式可根据推进器实际安装方向进一步调整。

---

### 2.5 通用控制

| 按键           | 功能                     |
| ------------ | ---------------------- |
| **M**        | 全通道归中（立即）              |
| **Z**        | 显示帮助菜单                 |
| **Esc**      | 安全退出程序（释放 RAW 模式）      |
| **Ctrl + C** | 强制退出（带 emergency stop） |

Esc 是最推荐的退出方式。

## 3. 安全限制机制（强工程约束）

### 3.1 限斜率（max_step_pct）

每步最大允许变化：**0.2%**
在 50 Hz 调度下：

```
每秒最大变化 = 0.2% * 50 = 10%
```

确保不会突然加速/反转，避免烧毁电机/供电模块。

---

### 3.2 分组更新（默认 AB 交替）

为避免 8 通道同时跃变引起电流浪涌：

* Group A：**CH1–CH4**
* Group B：**CH5–CH8**
* 控制频率 100 Hz → 每组实际 50 Hz

降低电源冲击，保护插件和电池。

---

### 3.3 禁止单步跨越中位反转

驱动层保证：

* PWM 必须从 7.5% → 匀速渐变 → 5% 或 10%
* 绝不允许瞬间 5% → 10% 或 10% → 5%

---

### 3.4 紧急停止机制

调用：

```cpp
pwm_ctrl_emergency_stop(1.0f);
```

在 1 秒内平滑回 7.5%。
系统异常（超时、通信失败等）会自动触发。

## 4. 主程序运行流程（逻辑图）

```
Start
│
├── 初始化 libpwm_host（UDP）
├── 初始化 pwm_control（限斜率+分组）
├── 所有通道设置为中位
├── 设置终端 RAW 模式
│
┌── Teleop 主循环（50Hz） ─────────────────────────┐
│   ├── 非阻塞读取键盘 read()
│   ├── 解析键盘 → 设置目标占空比
│   ├── 调用 pwm_ctrl_step() 平滑输出
│   ├── 心跳发送（1Hz）
│   ├── 接收 ACK，更新 RTT
│   ├── 打印统计（每秒）
│   └── sleep(周期)
└───────────────────────────────────────────────┘
│
├── emergency_stop()
├── 恢复终端模式
├── pwm_ctrl_deinit()
└── pwm_host_close()
```

## 5. 工程调试建议

### 5.1 初次带电测试

**必须拆掉螺旋桨！**

### 5.2 网络延迟检测

统计中会输出：

```
rtt= xx ms
```

一般应为 0.3–3 ms，超过 20 ms 需排查。

### 5.3 单电机逐通道检查

执行：

* 数字键 `1`~`8`
* 看示波器波形是否正确渐变

### 5.4 电源电流监控

如多通道同时动作电流偏大，应：

* 调低 MOVE_DELTA（默认 +0.5%）
* 增大 max_step_pct 限制
* 优化 Group A/B 分组
