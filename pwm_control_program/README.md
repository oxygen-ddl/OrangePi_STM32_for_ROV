# 水下机器人 PWM 推进器控制系统

## 项目概述

本项目是一个面向水下机器人的 8 通道 PWM 推进器控制系统，采用**三层架构设计**，确保控制安全、稳定可靠且易于扩展。系统通过 UDP 协议与 STM32 驱动板通信，支持键盘遥控、平滑控制、安全保护等核心功能。

---

## 系统架构

### 三层结构设计

| 层级 | 模块 | 功能描述 |
|------|------|----------|
| **顶层** | `pwm_teleop` | 键盘/遥控操作层，将用户输入转换为 PWM 控制指令 |
| **中间层** | `pwm_control` | 控制逻辑层，实现限斜率、分组输出、紧急停止等安全机制 |
| **底层** | `libpwm_host` | 通信层，负责 UDP 数据传输、心跳维护与链路监控 |

### 数据流

```
用户按键 → pwm_teleop → pwm_control → libpwm_host → STM32 → 推进器
```

---

## 核心特性

### 安全机制
- **限斜率控制**：PWM 占空比每步最大变化 0.2%，防止电流冲击
- **分组输出**：CH1-4 与 CH5-8 交替更新，降低瞬时负载
- **紧急停止**：一键平滑归中，所有通道安全回位
- **心跳监控**：持续检测通信链路健康状态

### 控制功能
- 8 通道独立 PWM 控制（1000-2000us 脉冲宽度）
- 单通道阻塞测试模式（工程调试专用）
- 多通道协同运动控制（前进、转向、升降等）
- 实时状态统计与 RTT 监测

## 快速开始

### 硬件要求
- Orange Pi 开发板
- STM32 PWM 驱动板（8 通道）
- 水下机器人推进器系统

### 软件运行
```bash
# 启动控制程序
./pwm_control_program 192.168.2.16 8000 50 1

# 或使用默认参数
./pwm_control_program
```

### 键盘操作指南

| 按键 | 功能 | 说明 |
|------|------|------|
| **1-8** | 单通道测试 | 阻塞式测试，通道平滑变化：7.5%→9%→7.5% |
| **W/S** | 前进/后退 | CH3+CH4 或 CH1+CH2 正转 |
| **A/D** | 右移/左移 | CH1+CH3 或 CH2+CH4 正转 |
| **Q/E** | 左转/右转 | CH1+CH4 或 CH2+CH3 正转 |
| **G/H** | 下潜/上浮 | 垂直方向推进器控制 |
| **M** | 全通道回中 | 立即将所有通道设为 7.5% |
| **Z** | 显示帮助 | 查看键位功能说明 |
| **Esc** | 安全退出 | 平滑停止并退出程序 |

## 工程测试流程

### 安全第一原则
- **必须拆除螺旋桨**进行初次测试
- 使用示波器验证 PWM 波形
- 监控电源电流，防止过载

### 测试步骤
1. **通信验证**：检查心跳 ACK 和 RTT 统计
2. **中位测试**：确认所有通道输出 1500us（7.5%）
3. **单通道测试**：逐个测试 1-8 通道的平滑变化
4. **运动测试**：验证水平、转向、垂直运动功能
5. **安全测试**：确认紧急停止功能正常
