# 水下机器人 PWM 推进器 —— 工程安全测试流程  
适用于 8 通道 PWM / UDP 控制方案  
（面向工程调试与新人培训）

---

## 1. 测试目的

确保以下内容在带电环境和空载环境中 **绝对安全**：

- 控制端到 STM32 的通信稳定性
- 8 通道 PWM 输出正确
- 限斜率机制生效
- 反向保护生效（不允许突然反转）
- 单通道电机测试行为符合预期
- 主控程序不会出现卡死、阻塞

---

## 2. 测试准备

### 2.1 必须满足的条件

- 已烧录 STM32 PWM 程序（带心跳与 fail-safe）
- 连接至局域网（OrangePi ↔ STM32）
- 终端可访问 STM32 的 IP（例如 `192.168.2.16`）
- 螺旋桨 **必须拆除**（初次测试）

### 2.2 必备设备

- 示波器（查看 PWM 上升沿/周期）
- 万用表（查看供电电压）
- 外接 12V/24V 稳压电源（根据推进器型号）
- 程序：`pwm_control_program`

---

## 3. 测试流程（推荐顺序）

---

## 3.1 步骤 1：验证 UDP 心跳通信

运行：

```
./pwm_control_program 192.168.2.16 8000
```

观察输出：

```
[STAT] tx_pwm=xx tx_hb=xx rx_hb_ack=xx rtt=1.x ms
```

检查内容：

- `rx_hb_ack` 是否持续增加（表示 ACK 到达）
- `rtt` 是否稳定（1~5ms 为正常）

如无 ACK：排查 IP/端口/网线/防火墙。

---

## 3.2 步骤 2：全通道中位测试

按键：

```
M
```

确认所有通道都输出 ~1500us（7.5%）。

示波器应显示：

```
周期为 20ms
高电平宽度约 1500us
```

---

## 3.3 步骤 3：单通道阻塞测试（强烈推荐）

按：

```
1
```

行为应为：

```
7.5% → 与限斜率升到 9.0% → 保持 3 秒 → 平滑下降到 7.5%
```

通道 1 的波形应该：

- **平滑上升**（无跳变）
- 停在 9% 约 3 秒
- 平滑下降到中位
- 其他 7 个通道保持 7.5%

对 1~8 逐个测试。

---

## 3.4 步骤 4：水平运动键测试

按：

```
W / S / A / D
```

预期行为：

- 只有 1~4 中部分通道增大占空比
- 最大偏移值为 `MOVE_DELTA=0.5%`
- 不允许突然反转
- 释放键后按 `M` 可以回中位

示波器可检查 2~3 个通道是否正确响应。

---

## 3.5 步骤 5：航向角控制测试

按：

```
Q  （左转）
E  （右转）
```

检查：

- Q 时 CH1 与 CH4 变大
- E 时 CH2 与 CH3 变大
- 其他不变

---

## 3.6 步骤 6：垂向运动测试

按：

```
G （下潜）
H （上浮）
```

其中（示例）：

```
下潜：CH5,CH8 正转；CH6,CH7 反转
上浮：CH6,CH7 正转；CH5,CH8 反转
```

检查是否符合推进器物理布局。

---

## 4. 安全检查（必须满足）

### 4.1 所有控制必须为**平滑变化**

任何通道：

- 不允许出现瞬间从 7% → 10%
- 不允许瞬间从正向跳到反向（限斜率 + 反向保护保证）

### 4.2 心跳必须稳定

`rx_hb_ack` 不应在运行中突然停止增长。

### 4.3 程序退出必须平滑归中

按 ESC 或 Ctrl+C 时：

```
pwm_ctrl_emergency_stop(1.0f)
```

执行：

```
所有通道 → 平滑下降 → 7.5%
```

---

## 5. 常见问题排查

### Q1. 程序按键无反应  
原因可能：

- 未进入 raw 模式（SSH 等）
- 键盘处理被阻塞
- pty 非本地终端

解决：

- 在本地 HDMI 终端运行
- 或在 SSH 上使用 `stty -F /dev/tty  raw -echo` 重新设置

---

### Q2. 心跳无 ACK  
检查：

- STM32 程序是否运行
- IP 是否配置错误
- 防火墙是否阻止 UDP

---

### Q3. 某通道不变化  
检查：

- 通道是否映射正确
- 是否被分组输出影响（A/B 交替）
- 目标值是否未设置成功
