# 📘 orangepi_send

香橙派（上位机） 与 STM32（下位机）之间的通信与 PWM 驱动控制模块

本模块实现了 **OrangePi → STM32 的可靠 PWM 控制链路**，提供 8 路推进器安全输出、心跳监控、通信协议解析与 CRC 校验，是整个 ROV 推进系统的底层执行单元。

---

## 1. 系统概述

### 功能目标

* 上位机周期性发送 PWM 指令、心跳包
* STM32 解析协议、校验 CRC、执行 PWM 输出
* 通信中断或异常时自动进入 **安全保护模式**

---

## 2. 系统架构

### 硬件结构

* **上位机**：OrangePi
* **下位机**：STM32F407（或 F446）
* **通信链路**：UDP over Ethernet（消息内容为“虚拟串口协议”）

### 软件结构

```
Teleop / MPC 控制层
        ↓
PWM 控制层（安全保护）
        ↓
通信协议层（UDP）
        ↓
STM32 执行层（PWM 输出）
```

---

## 3. 核心功能

### 3.1 安全保护机制

| 机制           | 描述                      |
| ------------ | ----------------------- |
| **限斜率保护**    | 每周期最大 0.2% 变化，避免电流冲击    |
| **A/B 分组输出** | 1–4、5–8 分组交替更新，降低瞬时电流峰值 |
| **反向保护**     | 禁止跨越中位瞬间反转              |
| **心跳监控**     | 500ms 无心跳自动回中位          |
| **平滑急停**     | 可设置时间，实现占空比平滑归中         |

这些保护**硬性保证推进器安全**，不依赖上层算法是否正确。

---

## 4. 通信协议（Protocol V1）

### 帧结构

```
SOF(2B) | VER(1B) | MSG_ID(1B) | SEQ(2B) | TICKS(4B)
LEN(2B) | PAYLOAD(N) | CRC16(2B)
```

### 消息类型

| 消息    | ID   | 描述         |
| ----- | ---- | ---------- |
| PWM控制 | 0x01 | 8 路 PWM 指令 |
| 心跳    | 0x10 | 上位机心跳      |
| 心跳应答  | 0x11 | STM32 回复   |
| 紧急停止  | 0x20 | 平滑急停或立即急停  |

### 校验方式

* CRC16-CCITT-FALSE
* STM32 端验证失败会丢弃并计入错误统计

## 5. 快速上手

### 5.1 STM32 端准备

* Keil 或 CubeIDE 工程
* UART5 DMA 接收通信数据
* TIM1 / TIM4 输出 8 路 PWM

### 5.2 OrangePi 端编译

```bash
cd orangepi_send
mkdir build && cd build
cmake ..
make -j4
```

生成：

```
libpwm_host.a
orangepi_send 可执行程序
```

### 5.3 运行程序

```bash
./orangepi_send 192.168.2.16 8000 51 1
# 参数说明：目标IP，端口，控制频率（Hz），心跳频率（Hz）
```

## 6. 测试流程

### 基础检测

1. **心跳延迟** < 10ms
2. 超时 500ms 内自动回中
3. CRC 错误时丢弃数据帧
4. 8 通道 PWM 输出稳定，无毛刺

### 安全功能验证

* 限斜率保护
* A/B 分组输出
* 平滑急停（验证插值是否平滑）

### 异常场景测试

* 拔网线（模拟丢包）
* 强制关闭上位机程序
* 发送错误长度 / 错误 CRC 帧

## 8. 工程价值

### 安全性

推进器绝不能失控，本模块内部完全隔离硬件安全，
即使上层算法崩溃、网络丢包、延迟过大，也不会损坏推进器。

### 可扩展性

上位机可以接入：

* Teleop 键盘控制
* MPC 控制器
* 强化学习策略
* ROS 2 控制栈

底层无需修改。

### 可维护性

* 独立 C 库 `libpwm_host.a`
* 清晰的 API 接口
* STM32 与 OrangePi 解耦良好
